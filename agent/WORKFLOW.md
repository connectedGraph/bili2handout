# Agent 工作流：从语料到观点讲义

这是本项目的核心方法论。管线脚本（`scripts/b2h.py`）负责把视频变成文字，
这一步负责把文字变成讲义。工作流与具体模型无关：Claude Code、ChatGPT、
Gemini、本地模型，任何能读长文档、能写文件的 Agent 都可以执行。

输入：`corpus/all_transcripts.md`（全部视频转写合辑）
输出：`handout/` 下一份可编译的 LaTeX 工程与 PDF

整个过程分五个阶段。每个阶段都给出**给 Agent 的提示词要点**，直接复制改写即可使用。

---

## 阶段 0：立场校准（最重要，先于一切写作）

在动笔前必须先想清楚三件事，否则成品会变成四不像：

1. **写给谁看**：是写给该博主的现有观众/认同者（社群内部的认知文），
   还是写给完全不了解博主的大众？本工作流默认是前者——
   「一个自我认同的小群体，用自己的黑话互相确认经验」。
2. **是什么体裁**：观点讲义，不是科普稿、不是医疗/专业建议、不是视频摘要。
   语气参照中文互联网的「知乎式认知长文」：第一人称对话感、先给反直觉判断、
   用类比而不是术语压人、承认猜测与个体差异。
3. **忠于什么**：忠于博主的**推理过程和原生概念**，不忠于字幕的字面顺序。
   允许重组、延伸、补充论证链；不允许替博主发明他没说过的观点，
   也不允许把口语里的猜想写成确定结论。

> 边界提示：素材若涉及医学、心理诊断、法律、投资等领域，成品必须显式标注
> 「这是观点与经验，不是专业建议」，并保留博主本人对不确定性的表述。

---

## 阶段 1：通读与提炼（corpus → digest.md）

**给 Agent 的提示词要点：**

```
你将读到一位博主 N 期视频的完整转写（corpus/all_transcripts.md）。
请通读后产出 digest.md，要求：

1. 一句话总纲：博主对整个主题最核心的判断是什么？
2. 世界观层：博主用哪些底层隐喻/模型解释这个主题？（如"算法""账本""燃料"）
   每个模型注明出自哪个 BV 号。
3. 概念词典：提取博主自创或反复使用的全部"黑话"，每条写清：
   术语 / 博主本人的定义 / 它解决什么问题 / 出处 BV。
4. 方法清单：博主给出的所有可操作方法，每条：做法 / 适用条件 /
   他警告过的代价或禁忌 / 出处 BV。
5. 观点冲突与演变：不同视频之间有没有矛盾、修正、程度差异？如实列出。
6. 反复出现的母题：哪些例子、金句、类比在多期视频里重复出现？
   这些是他思想体系的承重墙，讲义必须围绕它们组织。

只转述，不评价、不补充外部资料。区分"博主明确说的"和"可从多处推断的"。
```

`digest.md` 是后续一切的事实底稿。参考成品见
`examples/adhd-handout/digest.md`。

---

## 阶段 2：设计讲义架构（digest → outline）

视频是按发布时间散点排列的，讲义必须按**认知顺序**重排：
为什么会这样 → 具体表现/成因 → 怎么办 → 更深的思考。

**给 Agent 的提示词要点：**

```
基于 digest.md，设计一份 30~50 页讲义的章节架构（outline.md）：

1. 找到一条贯穿全文的主轴。好的主轴是一个"光谱"或"悖论"，
   能把不同处境的读者都装进去（例：同一套特征在不同外部条件下的两种命运）。
2. 用 4 个部分组织：
   第一部分 底层认知（世界观、核心模型、真正的问题是什么）
   第二部分 主轴上的分层画像（把理论延伸做在这里）
   第三部分 自救/方法论（认知调整 + 操作方法 + 分层策略）
   第四部分 更深一层的思考 + 一页纸清单
3. 每章写明：章标题 / 要回答的问题 / 使用 digest 中的哪些概念与方法 /
   引用哪几个 BV。
4. 设计附录：概念黑话速查表、出处对照表（BV → 章节）、
   面向读者的自检清单（可选）。
5. 章节之间必须有论证递进：后一章能回答前一章留下的问题，
   不允许出现两章讲同一件事。
```

架构定下来之后再写正文。架构错了，后面写得再好也要返工。

---

## 阶段 3：分章起草（outline + digest → chapters/*.tex）

逐章写作，每章一次 Agent 任务，而不是一次生成全书——
一次生成的长文会稀释观点、抹平章节差异。

**给 Agent 的提示词要点（每章复制一次，替换章号）：**

```
你要写讲义的第 N 章《标题》。素材：digest.md 的第 X 节，
原始出处：BVxxxx、BVyyyy（必要时回查 corpus/all_transcripts.md 对应段落）。

要求：
- 2000~4000 字中文，知乎认知长文语气：直接对"你"说话，
  开头先给一个反直觉或有共鸣的判断，再展开论证；
- 必须出现至少一个具体例子或类比，优先用博主本人举过的例子；
- 每章安排 1~2 个组件：
  核心洞察用 \begin{insight}…\end{insight}；
  边界、禁忌、风险提醒用 \begin{notehot}…\end{notehot}；
  可执行条目用 \begin{checklist}\item …\end{checklist}；
  段落级金句用 \key{…}；博主黑话首次出现用 \term{…}；
- 观点归属：关键论断后用（BVxxxx）标明出处；
  你做的延伸推理要写成自然的推论，不能伪装成博主原话；
- 章末用一句话或一个 \key{} 收束，并把问题交给下一章。
```

写作风格的细则见 [STYLE.md](./STYLE.md)，可用的排版组件见
[../docs/LAYOUT.md](../docs/LAYOUT.md)。

分章建议用并行的 subagent 各写一章，再由主 Agent 统一衔接——
但**主轴和章间过渡句必须由同一个 Agent 通读写定**，否则全书不连贯。

---

## 阶段 4：汇编与编译

1. 把 `template/` 整个复制为 `handout/`，替换 `main.tex` 中所有 `TODO`：
   标题、副标题、页眉、PDF 元数据、封面署名。
2. 按实际章数调整 `\input{chapters/chXX}` 列表。
3. 编译（需要本机装有 XeLaTeX，Windows 推荐 MiKTeX，macOS 推荐 MacTeX）：

   ```bash
   cd handout
   xelatex -interaction=nonstopmode main.tex
   xelatex -interaction=nonstopmode main.tex   # 第二遍生成目录与书签
   ```

   或 `latexmk -xelatex main.tex`。

---

## 阶段 5：质检（交付前必做）

**编译层：**

- [ ] 两遍编译均无 error；日志中 `Overfull` 数量为 0 或可接受；
- [ ] 中文没有乱码/缺字方块（重点检查自造符号、生僻字）；
- [ ] 目录页码、PDF 书签正确；封面与目录无页眉、正文从第 1 页计页。

**内容层（建议让一个新的 Agent 扮演审稿人）：**

- [ ] **事实回扣**：每个 \term 概念和关键论断都能在 digest/corpus 找到出处；
- [ ] **无发明**：没有博主没说过的观点被写成他的观点；
- [ ] **猜测标注**：博主本人说"不一定对"的地方，讲义同样保留不确定语气；
- [ ] **连贯性**：不看视频、只读讲义的人能跟上整条论证链；
- [ ] **合规**：医学/法律/投资等敏感领域的免责声明在位；
- [ ] **视觉**：表格不出血、tcolorbox 跨页正常、长表用 longtable；
      抽 3~5 页渲染成图片实际查看（`pdftoppm -png -r 80 main.pdf preview/p`）。

## 常见失败模式

| 症状 | 病因 | 对策 |
|---|---|---|
| 成品像视频分集简介 | 没做阶段 2，按 BV 号顺序写 | 强制先产出 outline，按认知顺序重排 |
| 通篇正确的废话 | Agent 用通用常识替换了博主黑话 | 概念必须用博主原词，阶段 1 黑话词典要全 |
| 像医疗/学术报告 | 立场校准缺失，写成了科普 | 重写为第二人称对话体，删除第三方研究引用腔 |
| 各章语气断裂 | 多 agent 并行后没人统稿 | 主 Agent 通读写过渡句与开头结尾 |
| 表格/盒子溢出页面 | 中文不可断行 + 固定列宽 | 用 p{} 列、`\emergencystretch`、longtable，见 LAYOUT.md |

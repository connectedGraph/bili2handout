# 实例：《最舒适的认知：ADHD 自救讲义》

这是用本仓库工作流产出的第一份完整讲义，作为各阶段产物的参照样例。

- **语料来源**：B 站 UP 主「阿卡迪萨」（mid 308598581）标题含 ADHD 的 24 期视频，
  本地 faster-whisper small 转写，约 12 万字；
- **成品**：`main.pdf`，37 页，四部分十一章三附录，XeLaTeX 零告警编译；
- **主轴**：同一套大脑特征，在「学历上层 / 学历中下层」两种外部条件下的
  不同命运、习惯与自救路径；
- **立场**：成人/自认 ADHD 社群内部视角的认知讲义，
  观点与经验整理，不是医学建议。

## 文件与工作流阶段的对照

| 文件 | 对应 WORKFLOW 阶段 |
|---|---|
| `digest.md` | 阶段 1「通读与提炼」的产物：总纲、世界观、黑话词典、方法清单 |
| `main.tex` + `chapters/` | 阶段 3/4：分章起草并汇编的 LaTeX 工程 |
| `main.pdf` | 阶段 4 编译产物 |

原始音频与逐期转写体积大且涉及博主版权，不随仓库分发；
`digest.md` 已包含全部观点的提炼与 BV 出处，足以复现讲义结构。
如需原始字幕，可按 README 的管线自行从公开视频转写。

观点属于「阿卡迪萨」，编排与延伸由整理者完成；如有曲解，责任在整理一方。
